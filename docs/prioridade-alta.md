# Melhorias no currículo — Prioridade Alta

Itens com maior impacto na triagem por recrutadores e ATS (Applicant Tracking System).

## 1. Adicionar métricas nos bullets da NTConsult

- [x] Quantificar resultados da experiência atual

**Problema:** a experiência mais recente não tem nenhum número. A Hogarth tem (6+ devs, scores 90+, 10+ sites, 20+ projetos), a NTConsult não.

**Recomendação:** usar a fórmula *verbo de ação + o que construiu + tecnologia + impacto mensurável*.

Exemplos do que medir:

- **IA:** tempo médio de correção de bug antes/depois, quantidade de tickets processados pelo workflow
- **SaaS agro:** número de usuários/clientes, módulos entregues
- **BFF:** quantidade de microsserviços agregados, ganho de latência
- **Liderança:** tamanho do time liderado

## 2. Mostrar o impacto do bullet de IA

- [x] Incluir resultado mensurável no tópico de workflows agênticos

**Problema:** o bullet descreve o workflow, mas não o resultado. Em 2026, citar apenas "Claude Code" é visto como algo comum ("o Microsoft Word de 2010").

**Recomendação:** mostrar o impacto (tempo, volume, qualidade) e o julgamento sobre o que a IA produz (quando confiar, quando revisar). Ex.: "…reduzindo o tempo médio de correção de X para Y".

## 3. Incluir palavras-chave faltantes na seção de Habilidades

- [x] Adicionar tecnologias já citadas nos bullets à seção de habilidades

**Problema:** o ATS procura termos na seção de habilidades, e várias tecnologias usadas na NTConsult não estão lá.

**Faltando:**

- **Testes:** Jest, Testing Library, Playwright
- **Banco de dados:** PostgreSQL, Redis
- **DevOps/Cloud:** Docker, GitHub Actions, GCP
- **Front-end:** Redux Toolkit, Highcharts, i18next

**Recomendação:** no CV Full stack, criar as categorias **Testes**, **Banco de Dados** e **DevOps/Cloud**.

## 4. Atualizar as tags de skills da NTConsult

- [x] Revisar a lista `skills` da experiência NTConsult nos 3 CVs (EN e PT-BR)

**Problema:** as tags listam JavaScript (em vez de TypeScript), Zustand e Storybook, mas não citam Playwright, PostgreSQL, Docker nem IA.

**Recomendação:** alinhar as tags com o conteúdo atual dos bullets.

## 5. Reescrever o "Sobre mim"

- [x] Atualizar o About nos 3 CVs (EN e PT-BR)

**Problema:** não menciona IA agêntica nem BFF, que hoje são diferenciais. Usa "Masters…" duas vezes, o que soa genérico.

**Recomendação:** abrir com o posicionamento atual (engenheiro com IA agêntica no fluxo de desenvolvimento) e cortar adjetivos genéricos. É a primeira coisa que o recrutador lê.
