# Melhorias no currículo — Prioridade Média

Itens que melhoram o posicionamento e a clareza do currículo.

## 1. Deixar senioridade e títulos claros

- [x] Revisar os títulos do cabeçalho e dos cargos

**Problema:** com mais de 11 anos de experiência, nenhum cargo diz "Senior". O cabeçalho usa "Engineer" e o cargo na NTConsult usa "Developer".

**Recomendação:** se for o caso, usar "Senior Full Stack Engineer" (e equivalentes), porque recrutadores filtram por senioridade. Padronizar entre "Engineer" e "Developer".

## 2. Informar o nível de inglês

- [x] Adicionar o nível em "Idiomas / Languages"

**Problema:** o idioma aparece sem nível. Em vaga remota internacional, isso é critério de eliminação.

**Recomendação:** ex. "English (Advanced/C1)", usando o nível real.

## 3. Deixar mais claros os nomes das habilidades de IA

- [x] Revisar a categoria "Inteligência Artificial / Artificial Intelligence"

**Problemas e sugestões:**

| Atual | Problema | Sugestão |
|---|---|---|
| Pi | Ambíguo para recrutador e ATS | Pi (coding agent) |
| Skills | Confunde com o título da seção "Skills" | Agent Skills |
| AI Memory | Vago | Persistent Agent Memory |

**Recomendação extra:** se usa outras ferramentas (Cursor, GitHub Copilot, OpenCode), listar reforça que o uso não depende de uma só ferramenta.

## 4. Separar projetos dentro da NTConsult

- [x] Deixar claro que são projetos/clientes distintos

**Problema:** a experiência mistura SaaS agro, painel ETL e Drupal/Gatsby em um cargo só, o que pode parecer disperso.

**Recomendação:** citar projeto ou cliente no início de cada bullet, ou agrupar por projeto.

## 5. Destacar diferenciais de front-end em alta (CV Front-end)

- [x] Avaliar se há experiência para destacar

**Contexto:** Next.js App Router/Server Components e UIs com IA (streaming via SSE/WebSocket, chat, agentes) são hoje os diferenciais mais procurados em vagas sênior de front-end.

**Recomendação:** se houver experiência real, adicionar ao About e às habilidades.
